# Quarto HTML 输出选项与生效边界

> 本文件记录 Quarto 面向 HTML 输出的选项语义、作用域层级与生效边界，是这块领域知识的唯一出处。
> 本仓库的实际取值以根目录配置为准，页面视觉实现以主题目录为准；正文写作约定由 skill 侧
> `.cursor/skills/quarto-docs/references/` 承载。配置为何静默失效、编码与路径的失效模式
> 见标识 cpp-tooling-quarto-render-v1 的知识文件。

## 选项的作用域层级

### 三层作用域决定谁覆盖谁

1. 项目级配置对整本书生效，是外观选项应有的落点
2. 文档级前置元数据只影响当前文件，会覆盖项目级的同名键，适合单篇实验而不是长期约定
3. 单元级选项写在代码块或 div 内部，只对那个块生效，优先级最高
4. 同一选项出现在多层时以作用域最小的一层为准，因此排查「配置没生效」先确认它写在哪一层
5. 站点级选项（导航、侧栏、分享）与格式级选项（目录、主题、代码块）分属不同键，混放后两边都不生效且不报错

### 外观配置集中一处

1. 整本书的格式块只写一次：散落到各章前置元数据后，同一类页面在不同章节呈现不一致，也没有单一处可核对
2. 项目级配置里已经含样式表清单，增删样式文件要同步改这里，否则新样式不参与渲染
3. 交付物的外观缺陷如果能靠浏览器缓存复现，先硬刷新再改配置，避免为缓存问题留下无效配置
4. 明暗双主题同时依赖内置主题与项目自定义样式，两者叠加顺序决定谁覆盖谁，调换顺序表现为颜色整体改变

## 目录与导航

### 目录的深度与位置

1. 目录默认收录到第二级标题，需要让读者看到更深的层级时显式加大收录深度
2. 目录可放在正文之前、页面右侧或页面留白处；窄屏下侧栏会折叠，因此右侧目录不能当作唯一的定位手段
3. 只有真实标题进入目录，加粗文本与裸 HTML 标题不会出现（成因见标识 cpp-tooling-quarto-render-v1 的知识文件）
4. 章节自动编号是可关的：关闭后标题里的序号只能手填，增删或调换小节就会与目录和交叉引用错位，所以标题不写序号
5. 目录里的文本来自标题而不是摘要，标题过长会把右侧目录挤成多行

### 章节链接与锚点

1. 交叉引用使用读者看得懂的稳定标签，标签一旦改名，原来指向它的引用会静默失去目标
2. 正文里引用章节、表格和插图各用各自的引用前缀，混用后引用文本会指向错误对象
3. 站内锚点由渲染器按标题文本生成：转小写、空格变连字符、标点和中文顿号被去掉，因此引用前先确认目标标题的实际文字
4. 页面同时存在前置元数据标题和顶层一级标题时，章节结构与目录一并错位（表现见标识 cpp-tooling-quarto-render-v1 的知识文件）

## 代码块显示

### 逐项列开关而不是使用已弃用的聚合值

1. 控制代码块外观的选项有开关和枚举两种形态：布尔值只表示开或关，需要按分组或按语言区分时必须写枚举值
2. 早期用于「一份代码多语言标签页」的布尔写法已被逐项列出的分组配置取代，继续写它只会得到弃用警告或不生效
3. 折叠、复制按钮和源码菜单是三件不同的事：折叠控制初始可见性，复制按钮控制可操作性，源码菜单控制能否看到源文件；只开折叠不会带来复制按钮
4. 长行的处理有两种：换行让代码保持完整但拉长页面，滚动保持页面宽度但隐藏行尾；面向新手的文档优先换行，读者不必横向拖动才能看懂
5. 折叠的代价是读者必须多点一次才看到实现，因此只对次要或重复的代码折叠，主线示例保持展开
6. 行号是第四件独立的事，它把读者注意力从代码内容引向行的位置，因此本仓库的文档默认不开行号；确需指向具体改动时在正文写出位置

### 语法高亮与明暗主题配对

1. 明暗两套高亮主题要分开指定：页面主题与代码高亮主题是两个各自独立的选择，互不推导，因此 light 与 dark 两组高亮配置要分别给出；只给一套时深色模式下会出现低对比度的注释与字符串
2. 高亮交给渲染引擎而不是自己写颜色：自定义颜色标记与引擎生成的标记冲突时表现为随机失配，且每次升级都要重做
3. 术语色、提示符配色、文件名条属于页面样式落在组件样式文件里，高亮属于渲染配置，两处混写会让同一段代码在不同页面表现不一致
4. 本仓库不使用代码行号：行号把注意力从内容引向行位置，确需引用具体行时用正文说明而不是全局开关
5. 高亮只对标注了语言名的围栏生效，缺语言名时按纯文本渲染；包含真实源码必须包进带语言名围栏的原因见标识 cpp-tooling-quarto-render-v1 的知识文件

### 可执行代码块与非代码围栏的边界

1. 花括号形式的围栏是引擎的特殊单元格标记，只有确实要执行或渲染的图表才用它；普通代码写成花括号形式会被当作待执行的单元格处理
2. 流程图按特殊图表围栏书写才会输出矢量图形，写成普通围栏只得到一个代码块，看起来渲染成功实际没有出图
3. 图表的配色与字体由页面样式控制而不是在配置里指定主题名：图表引擎读取样式变量，配置里再写一套会让两处不一致
4. 单元格选项既可以写在项目级或文档级作为默认值，也可以写在块内覆盖；块内选项使用引擎规定的注释前缀，写在普通注释里不会生效
5. 显示代码但隐藏输出、或只输出结果不显示代码，是同一类块级选项的两种组合，选一种就不要在正文里重复解释代码块已经写明的内容

## 产物与资源

### 依赖目录与额外资源

1. 单个文档渲染会附带一个同名依赖目录，里面有图片、样式和脚本；确认产物是单文件时要检查该目录是否消失
2. 项目级声明的额外资源目录整目录复制进产物，用于自托管字体与站点图标，路径写错表现为字体回落系统默认
3. 自托管字体需要页面头部引入字体声明文件，缺这一环时样式表里的字体声明找不到字形
4. 输出目录由项目类型决定，产物路径与上传路径必须与之匹配（部署侧的取舍见标识 cpp-tooling-pages-deploy-v1 的知识文件）
5. 产物目录只用于发布，不参与版本控制也不作为阅读与检索对象，检查一律交给脚本

### 单文件分发的选项归属

1. 单文件分发由内嵌资源选项控制，它与自包含数学选项分属两个开关，只开前者时公式仍然外链
2. 该选项必须嵌在格式块之内，放错层级的表现与根因见标识 cpp-tooling-quarto-render-v1 的知识文件
