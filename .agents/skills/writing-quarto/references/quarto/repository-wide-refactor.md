# 全仓 QMD 重构

本 reference 用于同时复核 `index.qmd`、各 part 首页和所有 `content/**/*.qmd`。它补充章节写作规则，不改变 `writing-cpp` 的语言教学职责。

## 范围与排除

读取 `_quarto.yml`、根入口、所有 part/index 页面、全部 QMD、任务矩阵、被正文引用的 `code/` 示例、构建脚本和验证脚本。排除 `_book/`、`.quarto/`、`_freeze/`、`temp/`、示例 build 目录和其他生成物；已有未提交改动不得用 reset、clean 或 checkout 覆盖。

## 递进与标题

入口页只说明分册定位和阅读顺序。每个正文页只交付一个 part/chapter 任务；先建立当前对象和最小例子，再展示操作和验证。标题描述任务结果，不用会随内容变化而失真的固定数量承诺。工具链命令只在读者已具备前置源码和工程上下文的页面出现，不能在过早的概念页提前完成构建验收。

## 收口

全量复核标题层级、导航、链接、代码摘录、命令、输出、术语和重复内容。先用增量检查定位问题，再对全部 QMD 运行内容预算、禁词、编码和链接检查，最后渲染 Book。修改示例时运行 `verify_examples.py` 和对应构建验证；修改知识时同步 `cpp-*` 索引和评测。只统一两仓的治理与验证边界，不复制 board-games 的 `bg-*` 规则。
