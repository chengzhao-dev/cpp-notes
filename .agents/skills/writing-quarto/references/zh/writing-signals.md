# 写作信号表：句段与注释对照

本文件是 `writing-howto.md` 的信号表分册：同一张表扫 `content/**` 与 `.agents/**`，按工序命中即改；工序定义与判定口诀见 `writing-howto.md`。

## 信号表（句段与注释，按工序命中即改）

同一张表扫 `content/**` 与 `.agents/**`；载体差异按知识 `cpp-quarto-chinese-quality-v1` 的载体适配表（压缩语域豁免不适用于读者正文）。高精度项由 `check_zh_lint.py` 固化，其余靠人工过表；「工序」列对齐 `writing-spine.md` 的写作工序：

| 工序 | 信号 | 判定 | 依据 |
| --- | --- | --- | --- |
| 定任务 | 正文「下一节／上一节」 | 删，改新节首句承接（章末「下一章」保留） | `cpp-quarto-paragraph-craft-v1` |
| 定任务 | agent 免责腔（「服务于讲解」「片段不保证」「不等于文件内顺序」、台账口吻声明） | 读者正文整句删除；同源保证交给 verify，规则留 `.agents` | `cpp-quarto-chapter-structure-v1`、`cpp-quarto-chinese-voice-register-v1` |

| 定段落 | 段内同义堆叠（两句换说法讲同一机制） | 删辅句或合并；公式递进与简洁边界豁免 | `cpp-quarto-paragraph-craft-v1`「段内同义堆叠禁令」 |

机械项：`check_zh_lint.py` 扫读者 qmd 与 agents 的 `下一节`/`上一节`、`代码把它写成`、`第二道…防线`、围栏外正文的 `由…完成`；读者正文的 agent 免责腔硬拦，章节页引言两个散文段、段落下限由 `verify_content.py` 判失败；段内连续分句引入新行内代码标识且无回指的过简断裂信号由 `verify_content.py` 记 WARN（不追清零）。句子模块切分由 `verify_content.py` 对扫描范围内的 qmd 全量执行，只印切分计数与失败行，失败收三类高精度信号（类型接线句、「接着看／第 N 个枚举」改口、全称被下一句否定）；段中心写不出与对话件数不做正则，留给工序与案例。

## 定段落删改检查清单

一段一个对象、段间衔接、概念负荷的判定依据见知识 `cpp-quarto-paragraph-craft-v1` 对应条目；对每个段落依次检查：

- 删掉后影响当前任务吗？不影响就压缩或删除。
- 段落是否同时承担两个以上动作？是就拆分。
- 同一小节的连续同源代码围栏先看是否是紧邻常量与其直接使用行：只有常量紧接着被下一行使用时才放在同一个围栏；类型定义和后一步使用它的函数是两步，即使函数用到该类型也分成两块，一个围栏只放正在讲的那一个声明或函数（对照见知识「递进片段合并」）。
- 段落是否推进了两个互不依赖的并列对象？是就按「拆核四步」处理：递进同段衔接、并列拆段，新段段首补衔接（对照见同知识「单段混并列对象」）。
- 段内是否有换说法复述同一机制的句子？是就删辅句或合并（知识「段内同义堆叠禁令」）。
- 分句骨架是否成立？设计说明先写代码决定、再补依据，逗号甩出独立判断，「由 X 完成」式被动交接，都在定句子判废（知识「句内骨架」）。
- 散文里是否有「话题标签：解释」词条腔？是就改完整主谓句或真列表项（知识「散文伪标签冒号禁令」）。
- 代码块后的段落是否在翻译块内注释？是就删除，只留注释没覆盖的新信息（对照见知识「块后复述注释」）。
- 树后或块后补写的新信息，主语有没有换成另一个对象（工具配置、依赖方向等本节标题未列的对象）？是就删除或下沉（对照见知识「树后换对象收束句」）。
- 读者能否指出完成后要观察什么？不能就补结果。
- 正文、代码块和回顾是否重复同一句话？重复就只留一处。
- 新术语是否由当前动作自然引出？不是就后置。标题与论据只准使用读者已建立的术语，未建立就删除或下沉（知识「小节标题与正文对齐」）。

相邻句子用因果、承接或对比关系连接，不用同义句重复中心。删掉一句后前后仍然通顺，说明这句只是重复。确认一个中心主题后，用衔接词把相关动作组织成连贯句；禁止把各自成句、互不衔接的罗列式短句机械堆进一段（对照见知识「罗列短句成段」）。禁止接口清单压缩段：公开接口用场景 → 代码 → 块后工程补白（对照见同知识「接口清单压缩段」）。
