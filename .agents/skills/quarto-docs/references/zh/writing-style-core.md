# 通用技术文档章节组织

先遵循 `writing-principles.md`。本文件只说明跨项目可复用的章节与页面组织。领域知识、环境步骤、命令和案例通过知识库检索获取。

## 章节主线

章节按“引言 → 正文 → 回顾”组织。

- 引言说明读者任务、前置条件与完成后的可验证结果。
- 正文按读者完成任务所需的顺序展开。每节只解决一个问题，先给结论或动作，再给理由、示例和边界。
- 回顾收束已完成的结果、验证方式和下一步入口，不重复正文。

## 标题与页面

- 标题描述读者能完成的任务或获得的认识，不使用空泛标签或手动序号。
- 标题后的首句直接兑现标题承诺。不能独立承担任务的短内容并入相邻章节。
- 页面摘要说明范围、读者和结果。卡片与索引只保留定位和导航，不复制正文。
- 有顺序的动作使用编号列表，并列信息使用无序列表。多项属性对比使用表格。

## 示例与展示

- 代码块前说明目的，代码块后给出结果、验证方式或下一步。
- 短技术标识使用行内代码。可复制的多行示例使用带语言标记的代码块。
- 目录树、命令、输出和图表必须来自可验证的实际状态。展示范围只覆盖当前任务。
- 代码注释说明当前学习重点，不逐行复述代码，也不提前引入未解释的概念。

需要当前项目的章节、环境、命令或展示案例时，运行 `python .agents/skills/agent-ops/scripts/run.py kb-search "Quarto 写作案例" --domain quarto-docs`。
