# 通用技术文档章节组织

先遵循 `writing-principles.md`。本文件只说明跨项目可复用的章节与页面组织。Quarto 元素写法见 `references/quarto/authoring.md`，领域案例通过知识库检索获取。

## 章节主线

章节按“引言 → 可选概览/结构 → 任务序列 → 常见错误 → 本章回顾”组织。只有读者需要先看静态对象或路线时，概览才作为独立信息块存在。

- 引言用普通段落说明读者任务、背景和范围，不与后续任务重复前置条件、命令或完成结果，也不放 Callout。引言不使用孤立的结论句，先交代读者为什么开始，再自然进入任务。
- 引言中的相邻事实要形成因果、转折或推进关系，不能只把几个正确句子并排堆放。
- 相邻的短结论句如果共同说明同一对象，应合并成有连接关系的段落，不把一句停顿拆成多段。
- 正文按读者完成任务所需的顺序展开。每节只解决一个问题，先给动作或结论，再给理由、示例和边界。
- 常见错误只处理失败分支，不重复正文；本章回顾在常见错误之后收束执行结果、关键问题和下一步入口。详细依据见标识 `cpp-quarto-chapter-pattern-v1`。

## 标题与页面

- 标题描述读者能完成的任务或获得的认识，不使用空泛标签或手动序号。同级标题保持一致的命名模式，删除可以移到首句或正文的限定条件；标题只保留读者要完成的任务或识别的核心故障。
- 多个 `###` 共享同一阶段、环境或产物时，可以用父级 `##` 统摄；父标题写阶段或范围，子标题写可验证任务，不能只把页面标题改写一遍。
- 标题后的首句直接兑现标题承诺。不能独立承担任务的短内容并入相邻章节。
- `##` 下不强制写导语。首个段落或 `###` 可以直接开始任务，只有导语补充任务顺序、前置条件、范围或标题未表达的结果时才保留，不能只复述标题和章节目标。
- 页面摘要说明范围、读者和结果。卡片与索引只保留定位和导航，不复制正文。
- 新手首次成功路径先给完整、可打开的示例或最小可运行结果，再展开目录树、参数和实现细节。入口与索引只承诺当前已经提供的内容，未完成的路线只保留后续导航。
- 卡片只写当前产物与可验证结果，不声称正文未安装、未展示或无法核验的能力。选择构建方式时只比较真正的构建工具，便利脚本应归入其调用的构建流程。
- 有顺序的动作使用编号列表，并列信息使用无序列表。三项以上且需要横向比较属性时使用表格。

## 表格选型

表格只用于横向比较三个以上对象的属性，不能把长故障分支或多个动作塞进单元格。常见错误按症状拆成 `###`，不使用表格。

| 读者在找什么 | 表头 | 最后一列 |
|---|---|---|
| 一个路径或文件的归属 | 路径 → 类别 → 作用 | 是否手改 |
| 一个命令选项的效果 | 选项 → 作用 → 默认或替代写法 | 常见误用 |
| 完成同一目标的多种做法 | 方式 → 适用场景 → 关键命令 | 代价 |

对照表放在读者已经跑通主线的地方，不打断首次成功路径。表格里只放短语和行内代码，一格放不下整句时改用列表或正文。

## 常见错误与本章回顾

常见错误在回顾之前，只服务失败后返回主线的读者。故障标题后的首句同时说明触发条件与可观察现象，具体诊断结构以 `references/quarto/terminal-validation.md` 为唯一出处。本章回顾用一段简短总结加不超过 3 个关键问题，问题只使用本章已经出现的内容；不默认使用勾选清单，也不用微型练习代替回顾。需要给出答案时，答案紧跟对应问题并使用 `references/quarto/authoring.md` 的“可折叠答案”格式，不集中到章末。需要额外练习时另行明确其验证目标。

## 示例与展示

- 代码块前说明目的，代码块后给出结果、验证方式或下一步。
- 短技术标识使用行内代码。可复制的多行示例使用带语言标记的代码块。
- 目录树、命令、输出和图表必须来自可验证的实际状态，展示范围只覆盖当前任务。
- 读者能从真实源码和注释辨认目标符号时，不再用独立导览表重复解释。

需要页面块序列、环境章案例或中文表达依据时，分别检索 `cpp-quarto-chapter-pattern-v1`、`cpp-quarto-chapter-environment-v1` 与 `cpp-quarto-chinese-style-v1`。
