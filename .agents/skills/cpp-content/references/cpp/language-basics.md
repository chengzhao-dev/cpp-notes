# C++ 语言基础教学顺序

本文件只规定语言基础 part 的章节边界、示例递进和后续扩展顺序。页面骨架仍按 `quarto-docs`，标准语义和译名先用 `cpp.md` 核对。

## 首版两章

`types-and-variables` 先建立“值属于类型，名字绑定变量”的心智模型。正文至少覆盖 `int`、`double`、`bool`、`char`、`std::string`、初始化、赋值、块作用域和 `auto` 入门，但一次只扩展一个变化点。

`constants` 再回答“哪些值不应改变”。先讲 `const` 的初始化与不可修改，再用一个短例子说明 `constexpr` 表示编译期可确定的值。不要把 `const`、指针常量和成员常量混在一页。

两章都使用单文件 `code/language-basics/<chapter>.cpp`，示例输出必须由 `verify --changed` 实测。正文用变量值变化和作用域观察结果验证概念，不把运行输出写成装饰。

## 后续顺序

后续章节按“先使用，再解释实现”的顺序扩展：

1. 运算符与表达式。
2. 条件、循环和代码块。
3. 函数、参数和返回值。
4. 字符串、数组和常用容器入口。
5. 自定义类型、类与引用。

新章节只在任务矩阵登记后创建，一次只引入一个主要变化。前一章已经演示过的语法不再复制完整示例，只保留当前主题需要的最小上下文。

## 百章扩展约束

part 的阅读顺序只写在 `_quarto.yml`，状态和示例只写在任务矩阵。新增章节时同步正文、示例、矩阵与必要索引，不建立并行章节表。

教学页按读者任务拆页，优先控制在 100 行和 4000 有效字符左右；达到 150 行或 5000 有效字符时必须先拆分或压缩。知识库只记录长期教学依据，不复制每章正文和 API 清单。

## 术语与验证

首次出现类型名、关键字和库类型时给出中文解释和英文检索词。`auto` 只能解释为编译期类型推断，不能写成“动态类型”；`const` 只能解释为不可通过该名字修改，不能承诺对象永远不变。

新增语言章节的最小验证包括：示例编译通过、输出与正文一致、任务矩阵状态更新、知识检索仍能命中对应教学依据。
