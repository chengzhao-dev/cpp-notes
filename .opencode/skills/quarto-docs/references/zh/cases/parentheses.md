# 括号示例 / 案例（writing-style.md 配套）

本文件是 `writing-style.md`「括号（（））的克制使用」的 before/after 案例库。规则见 `../writing-style.md`。

## 正文括号解释 → 成句

反面（把成因塞进括号，主句干瘪）：

```markdown
# 避免
只有更新或下载明显卡顿（多半是所在网络访问官方源偏慢）时，才换用镜像站加速。
```

正面（成因成句，与主句用逗号衔接）：

```markdown
# 推荐
只有更新或下载明显卡顿时，才换用镜像站加速，这多半是所在网络访问官方源偏慢导致的。
```

要点：括号内容与句子同等重要就成句；只是可删的细节（如「Ubuntu 上包名即 ninja-build」这类自指说明）直接删去。

## 环境标注 → 正式句子

反面（环境标注塞括号）：

```markdown
# 避免
在 PowerShell（管理员）中执行：
```

正面：

```markdown
# 推荐
以管理员身份打开 PowerShell 后运行：
```

要点：标注融入句子主干；与步骤标题「第 1 步：以管理员身份打开 PowerShell。」同一口吻。

## 示例路径 → 收住不展开

反面（括号举例，例子本身也属多余展开）：

```markdown
# 避免
可整体迁移到 D 盘（如 D:\ProgramData\WSL\Ubuntu）。
```

正面：

```markdown
# 推荐
可整体迁移到其他磁盘。
```

要点：括号去掉，举例也一并收住；具体盘符、路径由命令块承载（见 `../writing-style.md` 详略与衔接）。

## 表格标签保留括号

表格等紧凑场合的对照式标签不算正文长句，保留：

```markdown
| 适用状态 | 命令 | 作用 |
|:----|:--------|:---------|
| 运行中（Running） | `wsl --shutdown` | 终止所有 Linux 系统及底层轻量虚拟机 |
```

要点：规则只约束正文句子；表格标签、代码注释里的对照括号允许保留。
