# 本章回顾示例 / 案例（writing-style.md 配套）

本文件是 `writing-style.md`「本章回顾环节」的格式示例库。规则见 `../writing-style.md`。

定位：章末「本章回顾」用成就列表呼应章首「本章目标」，与「常见问题」「延伸内容」同属章末收尾；外部链接单列「相关资源」。

## 写作要点（提炼自既有规则）

1. **首句点题引导句（最重要）**：段首一句直接给结果（「你已经有了一套能编写 C++ 的…环境」），不用无意义标签（如「下面是本章总结：」）。
2. **直接讲重点，不复读目标列表（去重）**：回顾只写增量信息（怎么确认就绪、下一步能做什么）；bullet 与章首目标逐字重合就是重复，目标与成果一一对应、无增量时用 2–3 句重点句收束；列表仅在有多项增量时用（至多 3 条，重要章节至多 5 条，可选/延伸内容不列）。
3. **只写实际做过的事**：不夸大、不预列未实际演练的能力（如本章未实际调试 C++ 程序，就不写「调试」）。
4. **第二人称 + 鼓励式（文风基调）**：用「你」、主动、成就式措辞（「已掌握」「已搭好」），不堆虚词。
5. **相关资源（链接写法）**：外部链接单列「相关资源」，用描述性内联链接，不裸 URL。

## 反面：引导句空泛 + 夸大未做过的能力 + bullet 冗长 + 裸 URL

```markdown
## 本章回顾

下面是本章的总结：

- 我们学习了如何安装 WSL2，包括启用虚拟机平台、运行 wsl --install、设置用户名密码，并且验证了 wsl --status 显示默认分发是 Ubuntu、版本是 2，还学会了用 wsl --shutdown 和 wsl --terminate 来启动和关闭。
- 我们配置了软件源，当网络慢的时候换成清华镜像，然后安装了 gcc/g++、gdb、cmake、ninja 这些工具并验证了版本。
- 我们在 WSL 里写了第一个 C++ 程序，用 g++ 编译运行，并用 gdb 一步步调试了一遍。
- 我们把 WSL 从 C 盘搬到了 D 盘，用 wsl --export 和 wsl --import，或者 wsl --manage --move。

参考文档：https://learn.microsoft.com/windows/wsl/ 和 https://mirrors.tuna.tsinghua.edu.cn/help/ubuntu/
```

问题：引导句「下面是本章的总结：」是无意义标签；bullet 用「我们」旁观口吻、抄过程冗长且与章首目标近乎逐字重复；第三条声称「写了程序并用 gdb 调试」，但章节从未实际演示写/构建/调试 C++ 程序（只装了工具），属夸大未做过的能力；资源用裸 URL。

## 推荐：引导句给结果 + 直接讲重点（不复读目标）+ 资源单列

```markdown
## 本章回顾

你在 Windows 上已经有了一套能编写 C++ 的 WSL2 Ubuntu 环境。`wsl --status` 与 `--version` 随时能确认环境和工具链就位。接下来，就可以动手写第一个 C++ 程序。

### 相关资源

- [WSL 官方文档](https://learn.microsoft.com/windows/wsl/)
- [Ubuntu 换源帮助](https://mirrors.tuna.tsinghua.edu.cn/help/ubuntu/)
```

要点：直接讲重点——引导句给结果、随后写增量（确认方式 + 下一步），不复读章首目标；目标与成果一一对应、无增量时列表整段省去；相关资源用描述性内联链接。
