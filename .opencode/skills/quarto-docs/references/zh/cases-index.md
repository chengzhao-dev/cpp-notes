# 写作示例 / 案例索引（writing-style.md 配套）

写作规则在 `writing-style.md`；下方按主题列出配套 before/after 案例。agent 按规则内指针（或本索引）**按需只读对应文件**，不必通读，以控制上下文体积。

| 主题 | 案例文件 | 内容 |
|---|---|---|
| 长句三步 | cases/long-sentence.md | 章节引言散/聚、两类信息拆开（句/列表）、章节开头、解释冒号 |
| 相邻段落合并 | cases/adjacent-paragraphs.md | 启动/关闭主旨对齐、软件源三段合一段、迁移段合并 |
| 分号克制 | cases/semicolon.md | 非排比分号→句号 |
| 括号克制 | cases/parentheses.md | 正文括号补充→成句 |
| 详略与衔接 | cases/detail-level.md | 术语就地说清、直陈问题不拿示例指代、如·例如收敛、前向引用、验证判据 |
| 对比与解读 | cases/contrast-and-readout.md | 概念对比双条结论、代码后逐项解读、失败路径预判、设疑揭示、读输出提示 |
| 破坏性告诫 | cases/caution.md | 告诫三件套、可恢复边界、版本锚定 Note |
| 列表·列表项要短 | cases/list.md | 嵌套列表→三列表格、本章目标三步 |
| 路线图 | cases/roadmap.md | 引导句 + mermaid |
| 首页 Hero | cases/hero.md | 模式一/模式二 导语 |
| 常见问题 | cases/faq.md | 症状即标题、优先级三段、修复判据 |
| 延伸内容 | cases/supplementary.md | 章末按需内容（去冗余 / `>` 克制 / 注意块跟所属方法） |
| 本章回顾 | cases/chapter-review.md | 重点句（结果+确认+下一步）、列表仅在有增量时用、不复读目标 |

案例库可任意增长；单主题案例文件过大时再嵌套（如 `cases/long-sentence/intro.md`），索引保持单行条目。
