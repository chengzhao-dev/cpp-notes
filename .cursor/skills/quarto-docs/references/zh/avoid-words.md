# 禁用 / 慎用措辞表（cpp-notes）

本表是中文写作中**应避免词汇**的单一信息源。新增禁用词直接在此追加一行，不要散落到各写作规范正文。每条给出：禁用词、类别、推荐替代。

## 冗余虚词（无信息、可删）

| 禁用 | 替代 / 处理 |
|---|---|
| 完全 | 删去（「完全可行」→「可行」） |
| 即可 | 删去或改写（「补提交即可」→「补提交」） |
| 能够 | 删去（「能够提升」→「提升」） |
| 从零 | 删去（学习语境冗余，「从零开始学」→ 直接说动作，如「动手写出」） |
| 动手前 | 改用「开始前 / 操作前」，或直接用「先」带过（「动手前，先…」→「先在…」） |

## 空泛 / 过度承诺动词（承诺「让你彻底懂」，语气过满）

| 禁用 | 替代 |
|---|---|
| 吃透 | 梳理 / 拆解 / 介绍（「吃透类型系统」→「梳理类型系统」） |
| 讲清 | 梳理 / 拆解 / 介绍（「讲清容器」→「梳理容器」） |
| 独立 | 删去或改「动手」（「从零独立完成」→「动手写出」；承诺读者状态，属过度承诺） |

## 旁观语气 / 无信息 filler

| 禁用 | 说明 |
|---|---|
| 其实 | 删去 |
| 简单来说 | 删去 |
| 顾名思义 | 删去 |
| 本书 | 改用「本章 / 本节」 |
| 主流教程 | 删去，用「我们 / 一起来」带读者 |

## 公文腔动词（欧化 / 冗余绕行）

| 禁用 | 替代 / 处理 |
|---|---|
| 对 X 进行 Y | 直接动词（「对文件进行修改」→「修改文件」）；「操作在 X 里进行」这类主要动词用法合法，保留 |
| 加以 | 直接动词（「加以整理」→「整理」） |
| 作出 | 直接动词（「作出修改」→「修改」） |

## 程度词（营销腔强调，让事实说话）

| 禁用 | 替代 / 处理 |
|---|---|
| 非常 | 删去（「非常快」→「快」，给出具体数据） |
| 特别 | 删去 |
| 十分 | 删去 |

## 口语连接 / 收尾（技术书改书面递进）

| 禁用 | 替代 / 处理 |
|---|---|
| 然后 | 先…再…、随后（「然后运行 X」→「再运行 X」） |
| 接着 | 随后 / 再（时序递进不用口语黏连） |
| 的话 | 条件直接成句（「如果…的话」→「如果…」「…时」） |
| 等等 | 删去或列全（枚举到哪个说到哪个） |

## 慎用（例外见替代列）

| 慎用 | 处理 |
|---|---|
| 请 | 祈使直接给动作（「请运行 X」→「运行 X」）；「请看 / 参见」引导链接可保留 |

## 错用纠正（常见错别字 / 不规范词）

| 错用 | 正确 |
|---|---|
| 登陆 | 登录 |
| 帐户 | 账户 |
| 其它 | 其他 |
