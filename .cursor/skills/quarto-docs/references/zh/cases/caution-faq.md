## FAQ 闭环

症状标题 → 编号排查 → 「排查完成后运行 X，看到 Y 即成功。」

### 可套用模板

```markdown
## 常见问题

### 找不到 g++ 命令

1. 确认编译器已安装：`g++ --version`。
2. 若提示找不到命令，回到环境搭建章重装 `build-essential` 并验证 PATH。

重装后运行 `g++ --version`，能看到版本号即成功。

### build 目录能删吗

可以。`build/` 只放配置缓存和编译产物，删掉不会丢源码；需要时用 `cmake -S . -B build` 再生成。仓库通常用 `.gitignore` 排除它。
```

要点：

- 标题用**报错关键词或现象**，不是「为什么」。
- 标题与首段一体：像「能删吗」这类问题，首句先给可否结论和核心理由，再写步骤。
- 排查步骤**编号**、每步可独立操作。
- 结尾一句**验证判据**，让读者知道何时算解决。
- ≤3 条；进阶/迁移类问题独立成章，不塞进主线 FAQ。

## 版本锚定

整章一次 callout-note 声明验证环境（如 Ubuntu 26.04 + g++ 15），不在每步重复。
