# 列表与解读案例

## 并列条件（无序列表）

- Windows 10 2004 或更高版本，或 Windows 11。
- BIOS 或 UEFI 已启用 CPU 虚拟化。

有先后关系的动作改用有序列表，并列的条件、要求用无序列表，两类不混用。

## 工具安装表格

| 包 | 用途 |
|---|---|
| build-essential | g++、make |
| cmake | 构建系统 |

## 代码后解读

对比型知识点：先设问 + 双条结论，再给代码；多行输出用编号逐项说明。

## 详略

- 有官方文档的操作：决策 + 链接，不转抄全文。
- 验证：合并为「抽查 `g++` 与 `cmake` 的 `--version`」，不逐个工具重复段落，也不为环境可用性预先写长校验。
