# 句式案例

## 长句三步

- ✗ 「WSL2 是 Windows 里的 Linux 子系统，本章在 Windows 上用它搭好一套 C++ 开发环境，装好 Ubuntu，并配齐编译、构建与调试工具链。」
- ✓ 「WSL2 是 Windows 里的 Linux 子系统。本章在 Windows 上用它搭好 Ubuntu 开发环境，并配齐 C++ 工具链。」

## 分号

- ✓ 排比：「先装环境；再配工具；最后验证。」
- ✗ 非排比：「装好发行版；本节只演示最简安装。」→ 拆两句。

## 括号

- ✗ 「Ubuntu（默认装在 C 盘的用户目录）会占用空间。」
- ✓ 「Ubuntu 默认装在系统盘用户目录。空间不足时可迁移到其他磁盘（见延伸章）。」

## 相邻段合并

- ✗ 三段都说「进入 WSL2 后操作在 Linux 里进行」。
- ✓ 保留一处，其余删或并入步骤引言。

## 新手可读性（句子内说清）

**启动方式**

- ✗ 「启动：PowerShell 中 `wsl`，或打开 Ubuntu 应用；`wsl ~` 直接进入主目录。」
- ✓ 说明过长时标签独占行：

```markdown
- **启动 Ubuntu**

  在 Windows 开始菜单打开 **Ubuntu** 应用（等价于在 PowerShell 输入 `wsl`）。
  若已在 PowerShell，可用 `wsl ~` 直接进入 Linux 家目录（`~`）。
```

**状态命令**

- ✗ 「状态：`wsl --list --verbose` 查看 STATE 列。」
- ✓ 说明过长时拆段，并解释 `STATE`：

```markdown
- **查看是否在运行**

  在 PowerShell 执行 `wsl -l -v`。`STATE` 为 `Running` 表示正在运行；
  `Stopped` 表示已关闭。
```

**版本验证**

- ✗ 仅 `$ g++ --version` 两行，后接「其余工具需要时再查」。
- ✓ 各附代表性输出，并说明「看到版本号且无报错即表示可用」。

## 操作步骤

- ✗ `**第 2 步：安装工具。** 下表列出本章要装的包及其用途：`（标签与长句同行）
- ✓ 标签独占行，说明另起段：

```markdown
**第 2 步：安装工具**

下表列出本章要装的包及其用途：
```

- ✗ 列表长说明挤在标签后：`- **启动 Ubuntu**：……（三句）`
- ✓ 长说明拆段：

```markdown
- **启动 Ubuntu**

  在 Windows 开始菜单打开 **Ubuntu** 应用……
```
