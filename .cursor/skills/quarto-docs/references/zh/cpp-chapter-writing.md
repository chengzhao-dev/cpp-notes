# C++ 章节写作

先遵循 `writing-principles.md` 和 `writing-style-core.md`。本文件只规定 C++ 教学内容的组织，不替代语言语义与工具链知识。

## 教学路径

- 引言说明当前问题、已知前置和完成后可验证的能力。
- 正文先建立概念模型，再给最小可运行示例；扩展示例一次只增加一个新的语言规则或工程约束。
- 回顾说明规则、验证结果和后续主题；风险、性能或所有权结论必须说明适用边界。

## C++ 示例

- 首次出现的术语给出中文名称、英文检索词和适用的语言版本；后续固定称呼。
- 示例完整可运行，片段明确标出省略范围；代码注释只标记本节需要观察的行为。
- 规则型内容按“建议、理由、正例、边界、验证”呈现。
- 标准语义、复杂度、生命周期和失效规则从权威资料或项目知识库核对，不依据措辞习惯推断。
