# 中文写作核心规范（cpp-notes）

写/改 `.qmd` 时必读。结构见 `../quarto/authoring.md`；润色禁词见 `avoid-words.md`；案例按需查 `cases/`。

## 场景速查

| 你在写… | 看本节 |
|---|---|
| 章首引言 / 目标列表 | 总则、列表三步 |
| mermaid 路线图 | 列表三步（与目标互补，不重复） |
| 章末回顾 / FAQ | 章末结构 |
| 首页 Hero | Hero 描述 |
| 润色 / 新手可读性 | 总则、新手可读性、`cases/sentences.md` |
| 操作步骤（第 N 步） | 操作步骤排版 |

## 总则

- 用「你」，协作动作用「我们/一起来」；不用「您」、旁观 filler（见 `avoid-words.md`）。
- 短句、主动、一句一义；先跑起来再补原理；不预演 `##` 小节、不三处重复同一信息。
- 段落 ≤3 句；单句尽量 ≤20 字；复杂信息用列表/表格。
- 中英文/数字混排加半角空格（盘古之白）。

## 术语

- 英文术语首次加中文释义；C++ 专名保持英文（RAII、UB 等）。
- 新特性标版本（`C++20 引入`）；译名以 [zh.cppreference.com](https://zh.cppreference.com/) 为准。
- 同物同名：正文统一一种写法（如 WSL2）；命令用行内代码 `` `wsl` ``。

## 列表三步

引导句点题 → bullets 递进 → 末条或尾句呼应。每项宜短；成对「名—说明」用表格。

## 章末结构

- **本章回顾**：2–3 句或 ≤3 条，只写读者实际完成的事；不复读目标列表。
- **常见问题**：症状作 `###` 标题；≤3 条；排查步骤编号清晰。
- 进阶/迁移专题：**独立成章**，不进主线章正文。

## Hero 描述（index.qmd）

`description:` 写覆盖范围 + 一句收益（动词起头）；不写实现细节；不用「从零开始」等禁词。

## 标点克制

- 分号只用于排比并列；否则用逗号或句号。
- 正文少用括号补充，改写成独立句。
- 解释性冒号改句号拆句；保留「**标签**：」、引出命令块、注意块头三类冒号。

## 新手可读性（句子内说清）

**读者**：略懂电脑、未搭过 Linux/C++ 环境的新手——不是零基础，也不是熟手。

**核心**：**改句子，不加结构**。在现有标题、列表、表格、代码块内补信息；不为凑行数新增 `##` 或 FAQ。

| 手法 | 要求 |
|---|---|
| 命令前 | 写清在哪个窗口（PowerShell / Ubuntu 终端）、什么状态 |
| 命令后 | 给完整或代表性输出，说明如何判断成功/失败 |
| 术语 | 首次出现即释义（`STATE`、`build-essential`、`~` 等） |
| 列表/表格 | 每项能独立读懂：名 + 干什么 + 何时用 |
| 甩手掌柜句 | 删「显然」「其余需要时再查」类表述 |

**禁止**：为达标行数堆小节；clarity 优先于 `docs/structure.md` 行数预算。

案例见 `cases/sentences.md`（启动/状态/版本验证 before→after）。

## 操作步骤排版

步骤标签与说明**不要挤在同一行**，采用「标签独占行 → 空行 → 说明段 → 代码块」：

```markdown
**第 1 步：更新软件包索引**

`apt update` 拉取最新包列表；`upgrade` 升级已安装包（可选但建议）：

```bash
sudo apt update && sudo apt upgrade -y
```
```

规则：

1. **步骤标签**：`**第 N 步：动词短语**`，独占一行；句末不加句号。
2. **说明**：下一行起普通段落；仅术语、关键词可点缀加粗。
3. **代码块**：紧跟说明；演示块仍用 `$`。
4. **不用 `####` 做步骤**：避免 TOC 过密。
5. **列表短标签可同行**：`- **关闭指定发行版**：一句说明`（约 ≤40 字）；说明过长则拆成「加粗标签独占一行 + 缩进下一段」。

案例见 `cases/sentences.md`「操作步骤」。

- [ ] 列表引导句 + 三步结构；mermaid 与目标互补
- [ ] 命令块标明执行环境；演示块有代表性输出 + 判据
- [ ] 步骤标签独占行，说明另起段；代码块用 `$` 提示符
- [ ] 章末有回顾；FAQ 按需 ≤3
- [ ] 句子内说清，不为凑行数加结构
- [ ] 文件名纯 ASCII
- [ ] 命令在首次使用步骤出现，不提前引用
- [ ] 润色时对照 `cases/` 中对应主题（按需）
