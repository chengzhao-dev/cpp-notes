# Skill: code-review

对提交、改动或指定文件进行只读缺陷审查。重点发现对正确性、安全性、现代 C++ 规范与文档契约有实质影响的缺陷，不提主观风格琐碎意见。

## 任务路由

C++ 代码审查读 
eferences/cpp-review.md；Quarto 文档与排版审查读 
eferences/docs-review.md。改动涉及两者时按需加载，不读无关领域规则。

## 缺陷分级与输出格式

缺陷报告按优先级排序，无缺陷时直接输出 No findings.：

- P0: 严重阻断（内存破坏、未定义行为、死锁、CI/渲染崩溃）。
- P1: 高优缺陷（资源泄漏、悬挂引用、核心排版断链、功能性回归）。
- P2: 一般缺陷（冗余拷贝、未遵守 RAII、容器操作越界风险、缺少成功判据）。
- P3: 低优瑕疵（未采用现代 C++ 推荐语法、行尾冗长注释、中英文标点混用）。

格式示例：
[P1] 悬挂引用风险 — code/memory/smart-pointers/main.cpp:28
跟随一段简短说明，交代问题场景、错误成因及可操作的修复建议。

## 执行纪律

1. 只读审查：严禁修改文件、提交代码或推送分支。
2. 缺陷优先：只指出由本次改动引入的、有据可查的具体问题。
3. 审查完成后提供简短的风险概括与测试覆盖建议。
