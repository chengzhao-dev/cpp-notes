# Quarto 文档与排版审查准则

## 审查重点

审查 .qmd 章节正文、中文表达与 Quarto 特有语法规范：

- **DOM 与布局契约**：检查代码块是否符合 GitHub 风格；Mermaid 图表是否严格使用 ``{mermaid}`` 围栏；普通终端演示是否使用 	ext 代码块。
- **中文写作与体例**：章节是否按“目标 → 示例 → 操作 → 验证 → 排查”推进；是否在标题后第一句直接兑现承诺；正文反引号是否仅包裹真实技术对象。
- **结构与链接**：跨章交叉引用是否使用规范 @sec- 锚点；图片与本地文件引用是否存在；小节标题层级是否跳跃。
- **Callout 规范**：是否仅使用内置的 
ote、	ip、warning、important、caution 五类，严禁自定义类。

## 缺陷判定原则

- 导致渲染失败或死链的问题归为 P1。
- 破坏中文排版节奏、正文与代码块事实不一致归为 P2。
