# Skill: skill-maintenance

仅用于创建、扩展、合并或拆分仓库 `.cursor/skills/` 内容，不参与普通文档、C++ 或主题任务。

## 维护流程

1. 先读 `_CATALOG.md`、目标 skill、相关 reference 和 `check_skill_size.py`。
2. 运行 `python scripts/agent/check_skill_size.py --verbose`，确认当前 L1/L2 余量。
3. 搜索相近规则，优先合并到职责最接近的现有文件，并删除重复表述。
4. 新内容在预算内时直接补充；超出时先压缩措辞、合并相近主题和移除一次性案例。
5. 精简后仍超出时，同一 skill 按独立主题新增 L2 reference；只有具备独立任务领域和触发条件时才新增 L1 skill。
6. 新增或拆分后同步更新父级 `SKILL.md`、`_CATALOG.md` 和必要的路由说明。

## 重构边界

默认先读原文、引用和任务边界，再在原文件上局部重构；不因“重构”直接删除后重写，除非用户明确要求或原结构无法安全修复。需要改名、提取或拆分时，先比较新旧文件职责，保留有效信息；完成后从整体复核新旧文件的术语、链接、顺序和重复内容。目录、文件名、版本和命令输出可由磁盘或环境获得时，先实际获取，无法确认则不伪造结果。

## 完成条件

- 每个规则只有一个权威出处，不在多个 skill 中复制。
- L1 只保留路由和关键约束，L2 只承载单一主题的按需知识。
- 运行体量、编码、链接、仓库检查和 `git diff --check`；保留用户已有改动。
